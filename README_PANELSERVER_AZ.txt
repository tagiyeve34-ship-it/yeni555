PanelServer test versiyası

- Tətbiq adı: PanelServer
- applicationId: com.ailenezareti.panelserver
- Köhnə panelin üstünə yazılmır; ayrıca quraşdırılır.
- Dashboard-da xəritə yoxdur.
- Dashboard yalnız serverdə olan GPS + batareya faizi + zəng məlumatlarından hesablanır.
- Bu gün / dünən müqayisəsi: məsafə, hərəkət, dayanma, dayanacaq sayı, zəng sayı.
- Batareya analizi: günün sərfiyyatı, ən sürətli azalma intervalı, ehtimal olunan şarj artımı, yalnız batareya dəyişiminə əsaslanan istifadə intensivliyi göstəricisi.
- Zənglər: gələn / gedən / cavabsız, son zənglər, danışıq müddəti, ən çox danışılanlar.
- Dayanacaqlar və ən çox qaldığı yerlər GPS-dən hesablanır; təyin edilmiş zona ilə üst-üstə düşürsə zona adı göstərilir.
- Xəritə ayrıca full-screen saxlanılıb. Marşrut xətti qalınlaşdırılıb, ağ halo əlavə olunub, hərəkət sürətinə görə yaşıl/mavi/narıncı hissələrə bölünür və istiqamət oxları böyüdülüb.

Qeyd: Batareyanın sürətli azalması telefonun mütləq əlində olduğunu sübut etmir. Panel bunu ehtimal kimi göstərir.
